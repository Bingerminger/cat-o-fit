## Notes

- Cat-O-Fit is an independent, open-source hobby/community project.
- The app does **not** call any interfaces of the device and app providers listed above.
  Data from Apple Health arrives either as a file the user has exported themselves
  (ZIP, GPX, TCX) or is sent to your own server by apps on your own iPhone (Health Auto
  Export, Shortcuts). The only open online services the app uses – optionally and
  switchable off – are Open-Meteo (weather) and Open Food Facts (nutrition values), see
  [CREDITS.md](CREDITS.md).
- The comparison table in the README reflects the providers' public statements as of the
  date given, with sources. Outdated or incorrect entries will be corrected when pointed out.
- "VDOT" is used as an established technical term of training science; the underlying
  formulas are freely published (see [CREDITS.md](CREDITS.md)).
- Should a trademark owner object to a mention, it will be adjusted or removed once
  notified – please report it through the repository issues.

The name **"Cat-O-Fit"** and the technical project name **"catofit"** are project names of
this repository and are not claimed as registered trademarks.
